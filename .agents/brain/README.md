# LiquidDynamo — Agent Brain & Engineering Memory

This directory stores persistent agent architectural knowledge, system topology maps, execution ledgers, and remediation reports for **LiquidDynamo**.

## Directory Contents

- **`ENGINEERING_REMEDIATION.md`**: Complete architectural and root-cause analysis of the 5 engineering remediation phases implemented in LiquidDynamo 2.3.4 (subprocess orphan prevention, CoreGraphics TIFF safety, Quartz MediaKeyInterceptor CGEvent tap repair, Escape key floating panel key monitor, and expanded `.contentShape` card hitboxes).
- **`ARCHITECTURE_MAP.md`**: Structural mapping of all LiquidDynamo subsystems, controllers, models, and extensions.
- **`TASK_EXECUTION_LEDGER.md`**: Chronological record of major development milestones, release verification gates, and atomic task checkpoints under Agent Guard supervision.
- **`../../.agent/`**: Live Agent Guard runtime ledger (`ledger.json`), project brief (`brief.md`), project map (`project_map.md`), and step execution history (`history/`).
